# video-divulgazione
Progetto di montaggio automatico dei video divulgativi. I video stanno su Drive, non qui.
- `CLAUDE.md`: istruzioni per Claude Code. `config.json`: percorsi e profili dei computer.
- `scripts/`: configurazione e controlli. `src/`: composizioni Remotion. `public/fonts/`: font dei sottotitoli.
- `.claude/skills/`: regole di Remotion (versione fissata, non aggiornare senza dirlo). `.claude/settings.json`: permessi di routine.
Installazione e uso: vedi il documento "tutorial di installazione".
Controlli: `npm run verifica` (veloci) e `npm run verifica:completo` (modello Whisper e render di prova).
